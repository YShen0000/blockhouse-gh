# Blockhouse SDK API Documentation

Welcome to the **Blockhouse SDK API Documentation**. This SDK is designed to provide seamless integration with the Blockhouse API, enabling developers to fetch and transfer trade data to Kafka topics with ease.

## Features

- Fetch trade data directly from the Blockhouse API.
- Automatically transfer data to Kafka topics.
- Simplified and efficient interface.

## Installation

To use the Blockhouse SDK, you can install the package via **pip**, the Python package installer. Ensure you have Python installed on your system.

### Steps to Install

1. Open a terminal or command prompt.
2. Run the following command:

```bash
pip install blockhouse
```

3. Verify the installation by checking the package:

```bash
pip show blockhouse
```
