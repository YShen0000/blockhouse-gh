# Feature of High-Low Volatility
## 1. Principle of the Feature
- 1. This feature provides a new way to estimate the volatility.
- 2. Beckers's study shows estimations based on high-low prices are more accurate than that based on closing prices.
- 3. This feature provides two ways to estimate the volatility
