# Explanation for Feature of CS_soread
## 1. Priciple of the Feature
- This feature measures the size of bid-ask spread.
- This feature was developed based on the study of Corwin and Schultz.
- The basic idea is that high prices always match against the offer and low prices match against the bid. Thus, the ratio of high-to-low reflects bid-ask spread.
- The research believed that the high-to-low ratio elapsed between two observations, which is why we use two periods of data to calculate the feature.
