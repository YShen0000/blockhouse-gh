Hoodwinked Charts — Stock Trading Analytics

Overview

Hoodwinked (HW) Charts is a stock trading analytics project that helps traders visualize the potential cost savings they can achieve by optimizing their trading strategies. The system compares the client's trade execution with HW's optimal execution using advanced machine learning techniques, specifically Long Short-Term Memory (LSTM) models, to showcase the benefits of the HW platform over traditional benchmarks like TWAP (Time-Weighted Average Price) and VWAP (Volume-Weighted Average Price).

The project provides users with a visual analysis of their trading strategies, demonstrating potential savings and excess returns, making it easier to interpret why Hoodwinked is valuable.

---

 Features

- LSTM-Based Analysis: The project utilizes LSTM models to predict optimal trade execution and compare it against traditional execution strategies.
- Transaction Cost Savings: Users can visualize the potential cost savings compared to TWAP and VWAP execution strategies based on their trade size and frequency.
- Chart Visualization: The system generates charts to show comparisons between client trades and optimal HW execution. These charts are returned as JSON responses for easy visualization.
- Flexible Trade Size Estimation: By fitting a polynomial model, the system can estimate cost savings for any trade size, not just predefined points.

---

 Key Modules

 1. chartCalculator.py

- Location: `Analytics/views/chartCalculation.py`
- Purpose: This module processes client trade data and calculates cost savings by comparing traditional execution strategies (TWAP/VWAP) with LSTM-generated optimal execution.
- Functions:
  - `process_columns(df, X, twap=True)`: Processes LSTM predictions and computes periodic prediction advantages against TWAP/VWAP.
  - `lstm_twap_cost_savings_calc(weekly_shares_traded)`: Calculates the estimated cost savings compared to TWAP for a given trade size.
  - `lstm_vwap_cost_savings_calc(weekly_shares_traded)`: Calculates the estimated cost savings compared to VWAP for a given trade size.
  - `calculate_cost_savings()`: Computes total annual cost savings, cost savings percentage, and excess returns based on user inputs (e.g., trade size, frequency).

 2. Data Collection

- Sources:
  - Client trade data: Imported from CSV files provided by the user, typically fetched via Plaid integration.
  - LSTM predictions: Generated by the Hoodwinked system and read from CSV files.
  
---

 Data Processing & Transformation

 Processing Flow

1. Data Import: Client trade data and LSTM projections are imported and loaded for processing.
2. TWAP/VWAP Comparison: Using the `process_columns()` function, we compare the client's trade costs to LSTM-based predictions and calculate savings.
3. Polynomial Fitting: We fit a degree-15 polynomial model to log-transformed data to generate cost savings predictions for any trade size, allowing continuous savings estimation.
4. JSON Response: The estimated savings and necessary data are formatted and returned as a JSON response, which is used to generate charts via Recharts or other charting libraries.

---

 Chart Generation

- Charts are generated using external front-end tools like Recharts.
- The module does not handle the actual chart rendering but provides the necessary data for visualizations in JSON format.
- This allows traders or affiliates to easily share their results on social media or within presentations.

 Installation

 Prerequisites

- Python 3.8+
- pip: Python package manager
- pandas: For data manipulation
- NumPy: For numerical computations
- scikit-learn: For machine learning utilities

 Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/Blockhouse-Repo/Blockhouse-ML.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Blockhouse-ML
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Set up your environment variables for client data (e.g., API keys for Plaid integration).

---

 Usage

1. Run the Chart Calculation Module:
   Use `chartCalculator.py` to process client data and generate the potential cost savings.

   ```python
   from Analytics.views.chartCalculation import calculate_cost_savings

   result = calculate_cost_savings(user_benchmark, user_time_period, user_order_size, sp_returns, user_frequency)
   print(result)
   ```

2. Visualize the Savings:
   - After running the module, you'll receive a JSON response containing data for chart visualization.
   - Integrate with front-end tools like Recharts to create visual representations of the potential savings.

---

 Example

Here’s a brief example of how to calculate weekly cost savings using LSTM compared to TWAP:

```python
from Analytics.views.chartCalculation import lstm_twap_cost_savings_calc

trade_size = 1000
savings = lstm_twap_cost_savings_calc(trade_size)
print(f'If you trade {trade_size} shares a week, our model will save you ${savings:.2f} compared to TWAP every week.')
```
